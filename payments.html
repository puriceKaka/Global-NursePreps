M-Pesa payment workflow

Use the M-Pesa option at enrollment, confirm the course name and price, then submit the transaction code for verification and course unlocking.

  1. Register or login with the student account that will own the course.
  2. Select the exact course, licensing track, mock exam, or support service.
  3. Choose M-Pesa, pay from your phone, then save the transaction code.
  4. Access opens only after the selected item is confirmed as paid.
